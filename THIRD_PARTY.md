# Third-party content

Skills in this plugin are rewritten and distilled for monday Vibe. Values, rules and patterns
come from the sources below; both are MIT-licensed, and their notice is reproduced here.

## emilkowalski/skills
- Source: https://github.com/emilkowalski/skills — MIT, Copyright (c) Emil Kowalski
- Used in: vibe-motion-pass (emil-design-eng, animate, find-animation-opportunities,
  review-animations, animation-performance), vibe-mobile-pass (mobile-native, animate-expo),
  vibe-break-test (break-ui + catalog), vibe-design-explore (prototype), vibe-motion-words
  (animation-vocabulary), vibe-design-direction (apple-design §15–16).
- Local reference copy: `scripts/sync-emil-skills.sh` clones it into `vendor/` (git-ignored).

## Leonxlnx/taste-skill
- Source: https://github.com/Leonxlnx/taste-skill — MIT, Copyright (c) 2026 Leonxlnx
- Used in: vibe-design-direction and vibe-screen-review (references/app-screens.md and the
  page run in SKILL.md), vibe-mobile-pass (app-screens §12).
- Its scripts (draw/inspect/lint/assets) are not bundled. Install upstream to run them:
  `npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"`
